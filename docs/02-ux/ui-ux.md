# UI / UX Design

Canonical visual direction lives in [`DESIGN.md`](../../DESIGN.md) at the project root (antislop + product identity).

This file keeps product UX notes. If the two disagree, **DESIGN.md wins for visuals**.

## Design north star

Feel **familiar like Google Meet**, then layer interview coaching chrome (question card, think timer, transcript, feedback) without turning the first viewport into a dashboard.

## Screens

### 1. Lobby / pre-join (dark)

- Large self-preview with Enable camera
- Segmented level control
- Quiet focus tags
- Start interview (Meet green)
- Past reports as text links

### 2. Live session (dark)

- Three tiles: HR, Technical, You
- Question + transcript + feedback under tiles
- Bottom Meet-style control bar

### 3. Report (light)

- Reading list of Q/A with delivery metrics and tips
