# Cheat sheet

## Prompt

Use everything from decode → predict → interview + feedback. Produce a **2-page** sheet readable in **~10 minutes**:

1. Intro (“tell me about yourself”) for the selected intro length, natural speaking tone
2. 3 strongest stories — 3 lines each (situation / what I did / result)
3. 5 concepts struggled with — 2 lines each
4. 3 company points to bring up naturally
5. 3–4 smart questions to ask at the end

## Runtime

`POST /api/prep/cheat-sheet`. Persist `CheatSheet` on pack. Optional PDF export.
