# Interview Sections

Fixed order for v1 sessions.

## 1. Introduction — HR

**Goal:** Warm up; get a structured self-intro.  
**Typical prompts:** Tell me about yourself; walk me through your background.  
**Success feel:** 1–2 minutes spoken; clear present–past–future arc.

## 2. HR QnA — HR

**Goal:** Motivation, transitions, company fit, soft skills.  
**Topics:** Why leave / looking; why this company/role; strengths & weaknesses; conflict; communication; career goals; what you know about us (use placeholder company profile in MVP).  
**Tone:** Conversational; one question at a time.

## 3. Tech stack — Technical

**Goal:** Tools and languages the candidate actually uses day to day.  
**Topics:** Languages, frameworks, databases, cloud, CI, testing; why those choices.  
**Tags:** javascript, csharp, dotnet, etc.

## 4. Project — Technical

**Goal:** Ownership story: problem, approach, tradeoffs, result.  
**Topics:** Hardest bug; something you shipped; teamwork; what you would redo.  
**Structure to coach later (not graded MVP):** Situation → Task → Action → Result.

## 5. Technical deep-dive — Technical

**Goal:** Tricky, level-appropriate technical questions so the candidate stretches.  
**Junior:** fundamentals (OOP, HTTP, SQL basics, debugging).  
**Mid:** APIs, async, testing strategy, performance basics, design of a small feature.  
**Senior:** system tradeoffs, reliability, mentoring, architecture boundaries, incident response.  
**MVP:** Verbal answers only (no live coding IDE).

## Suggested counts per session (default)
